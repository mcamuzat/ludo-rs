# Das glorreiche Manöver Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter Das glorreiche Manöver (course de 84 cases, 2 à 4 joueurs, jeu de base) à ludo-rs, jouable contre l'IA et en ligne.

**Architecture:** Une crate `games/manoever` sur le modèle de `games/bantu` : coordonnées du plateau relevées dans le PDF par un script, règles pures dans le moteur (dé de la mise en place tiré d'une graine, puis information parfaite), vue complète, IA ISMCTS générique. Le site dessine le plateau d'après un `board.json` produit par un test, et surligne les destinations calculées par le moteur.

**Tech Stack:** Rust 2021 (`rand` 0.8, `rand_chacha` 0.3, `serde`), Python 3 + `pdftotext`/`pdftocairo` (script hors build), React + TypeScript (Vitest).

**Spec:** `docs/superpowers/specs/2026-10-22-manoever-design.md` (à lire en entier avant chaque tâche).

## Global Constraints

- id du jeu `manoever`, nom affiché « Das glorreiche Manöver », crate `manoever`, type `Manoever`, 2 à 4 joueurs, `hidden_info: true`, `clock: true`, famille web `board`.
- Sièges et couleurs : 0 rouge, 1 jaune, 2 bleu, 3 vert. Soldats par joueur : 6 / 4 / 3 pour 2 / 3 / 4 joueurs, numérotés à partir de 1.
- Pièces bonus fixes : noires 12, 20, 47, 65 ; blanches 8, 24, 31, 36, 60, 74 ; grises 25 (1), 40 (2), 55 (3).
- `ludo-core` et `games/*` restent natifs : jamais de `wasm-bindgen`, `js-sys`, `web-sys`.
- Hasard : `ChaCha8Rng` seulement, tirer des `u32` (jamais `gen_range` sur `usize`). La graine ne va jamais dans une vue.
- `apply` renvoie `Illegal` sans modifier l'état et ne panique jamais, quelle que soit l'entrée.
- Le PDF (`~/Téléchargements/glorr_rg.pdf`) n'est jamais copié dans le dépôt, ni ses rendus.
- `RULES.md` cite [R], [B], [K] ou [U] pour chaque règle ; ❓ pour ce qui est déduit (liste au §9 de la spec).
- Messages et textes affichés en français.
- Avant chaque commit : `cargo fmt --all` et `cargo clippy --workspace --all-targets -- -D warnings` ; tests ciblés `cargo test --release -p manoever`.
- Commits avec l'e-mail du dépôt (`marc.camuzat@gmail.com`, déjà configuré localement), terminés par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Un joueur bouge le soldat du haut d'une pile et libère son propre soldat dessous : celui-ci doit bouger dans le même tour, et le tour ne finit pas avant (test Task 3).
2. Un soldat sur la case 84 (ou proche) dont le maximum dépasse la caserne : une seule action `Barracks`, jamais de `Square(n)` au-delà de 84 (test Task 3).
3. Après qu'un joueur a bougé, un adversaire dont tous les soldats sont recouverts est sauté sans action de sa part, et le tour revient au bon siège (test Task 3).
4. Une entrée absurde (`Square(0)`, `Square(200)`, soldat 9, soldat déjà déplacé, `Roll` hors mise en place) : `Illegal`, état inchangé (test Task 3).
5. Le Board reçoit une nouvelle vue (le tour passe, un soldat vient de bouger) : la sélection est effacée si le soldat sélectionné n'est plus à déplacer (test Task 5).

  - `pub fn find(s: &State, soldier: Soldier) -> Option<(Square, usize)>` (case, index dans la pile)
  - `pub fn position(s: &State, sq: Square) -> u8` : 1 + nombre de cases occupées strictement après `sq`
  - `pub fn height(s: &State, sq: Square, index: usize) -> u8` : `index + 1 + (disc(sq).is_some() as u8)`
  - `pub fn bonus(sq: Square, index: usize) -> u8` : 3 noire / 2 blanche si `index == 0`, sinon 1
  - `pub fn max_move(s: &State, soldier: Soldier) -> u32`
  - `pub fn room(s: &State, sq: Square) -> bool` : `stacks[sq].len() + disc(sq).is_some() as usize < 3`
  - `pub fn destinations(s: &State, soldier: Soldier) -> Vec<Dest>` : cases `sq+1 ..= min(sq+max, 84)` qui ont de la place, puis `Barracks` si `sq + max > 84` ; vide si le soldat n'est pas libre
  - `pub fn to_move(s: &State, seat: Seat) -> Vec<u8>` : numéros des soldats libres de `seat`, absents de `moved`, avec au moins une destination, croissants
  - `pub fn scores(s: &State) -> Vec<u32>` : places + pièces grises
