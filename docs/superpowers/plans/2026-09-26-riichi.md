# ludo-rs : Mahjong Riichi — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Jouer une hanchan de Mahjong Riichi (règles Mahjong Soul) sur ludo-rs, contre l'IA ou en ligne avec un chrono, en s'appuyant sur `riichienv-core`.

**Architecture:** Un crate `games/riichi` enveloppe le `GameState` de riichienv-core : il met en attente les réponses simultanées, sérialise l'état par rejeu (graine + actions), construit des vues par siège, redistribue l'information cachée pour l'ISMCTS et calcule le résultat de chaque main. La plateforme gagne l'action par défaut au chrono, l'attente visible par joueur, des budgets d'IA par jeu et une coupure des simulations ; côté web, `Table` tient le chrono, joue les actions uniques et relance l'IA en échec.

**Tech Stack:** Rust stable, `riichienv-core =0.4.10` (Apache-2.0), `rand 0.8`, `serde`; React 19 / Vite 7 / Vitest 3 / PeerJS 1.5 ; tuiles SVG FluffyStuff (CC0).

**Spec:** `docs/superpowers/specs/2026-09-26-riichi-design.md` (et la spec du cycle 1 pour la plateforme).

## Ajustements par rapport à la spec (reportés dans la spec à la tâche 11)

1. **Attente visible par joueur** : `Game::visible_pending(s, viewer)` (défaut : `pending`). Au Riichi, pendant une fenêtre d'appel, un joueur ne voit que lui-même en attente : sinon l'`Update` révélerait qui peut appeler. Les chronos envoyés suivent la même règle.
2. **Résultat de main** : riichienv enchaîne la main suivante dans le même `step` et efface `win_results`. On évalue donc les victoires **juste avant** le `step` avec son `HandEvaluator` public et les mêmes conditions ; les variations de score viennent du moteur (différence avant/après). Un test vérifie que nos points égalent ses variations.
3. **Pas de pause entre les mains** : la main suivante commence aussitôt ; le résultat reste dans la vue (`lastHand`) et l'interface l'affiche en surimpression.
4. **`Ankan { tile }`** au lieu de `Ankan { tiles: [Tile; 4] }` : la tuile suffit à désigner le kan.
5. **Défausse de l'IA** : à shanten égal, départage par une valeur de tuile (honneur isolé < terminale < 2/8 < centrale, cinq rouge gardé) plutôt que par le compte de tuiles utiles (trop coûteux à chaque pas de simulation).
6. **Conformance** : l'aller-retour serde de l'état est vérifié aux 20 premiers coups puis tous les 25 coups (au Riichi, relire l'état rejoue la partie).
7. **Déterminisation** : les mains redistribuées d'un adversaire en riichi ne sont pas forcées tenpai (approximation acceptée pour l'IA).
8. `Heuristics::budget(level, timed)` remplace `Search::timed`/`Search::counted` ; `AnyGame::ai_move` prend `(level, timed, seed)`.

## Review Focus

1. **Fuite par la fenêtre d'appel** : pendant qu'un joueur réfléchit à un pon/ron, les autres ne doivent voir ni qu'il est sollicité ni son chrono (Tâches 1, 3, 7, 9 : tests `visible_pending`).
2. **Course entre le chrono et le joueur** : l'hôte applique l'action par défaut, puis la réponse du joueur arrive → refusée comme périmée, l'état n'est pas joué deux fois (Tâche 8).
3. **Rechargement de l'hôte pendant une fenêtre d'appel** : des réponses déjà reçues doivent survivre à la reprise (Tâche 3 : aller-retour serde avec réponses en attente).
4. **Cinq rouge** : cliquer le 5 rouge défausse le rouge, pas un 5 ordinaire (Tâche 2 : actions distinctes ; Tâche 10 : clé par notation).
5. **Chrono après « Riichi »** : l'action par défaut doit être une défausse qui garde le riichi valide (Tâche 3 : `timeout_action` légale après Riichi).

```rust
pub struct Counter;

#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct CounterState {
    pub n: u32,
}

impl Game for Counter {
    type State = CounterState;
    type Action = u8;
    type View = CounterState;
    type Config = ();

    fn meta() -> GameMeta {
        GameMeta { id: "counter", name: "Counter", min_players: 1, max_players: 1, hidden_info: false, clock: false }
    }
    fn new(_config: &(), _players: u8, _seed: u64) -> CounterState {
        CounterState { n: 0 }
    }
    fn pending(_s: &CounterState) -> Pending {
        Pending::one(Seat(0))
    }
    fn legal_actions(_s: &CounterState, seat: Seat) -> Vec<u8> {
        if seat == Seat(0) {
            vec![1, 2]
        } else {
            Vec::new()
        }
    }
    fn apply(s: &mut CounterState, seat: Seat, a: &u8) -> Result<(), Illegal> {
        if seat != Seat(0) || !(1..=2).contains(a) {
            return Err(Illegal::new("coup interdit"));
        }
        s.n += u32::from(*a);
        Ok(())
    }
    fn view(s: &CounterState, _viewer: Viewer) -> CounterState {
        s.clone()
    }
    fn outcome(_s: &CounterState) -> Option<Outcome> {
        None
    }
}

impl Determinize for Counter {
    fn determinize<R: Rng + ?Sized>(s: &CounterState, _observer: Seat, _rng: &mut R) -> CounterState {
        s.clone()
    }
}

impl Heuristics for Counter {
    fn rollout_action<R: Rng + ?Sized>(_s: &CounterState, _seat: Seat, rng: &mut R) -> u8 {
        rng.gen_range(1..=2)
    }
    fn evaluate(root: &CounterState, sim: &CounterState) -> Option<Vec<f64>> {
        (sim.n >= root.n + 5).then(|| vec![1.0])
    }
}
```

```rust
fn rollout<G: Game + Heuristics>(root: &G::State, mut sim: G::State, rng: &mut SmallRng) -> Vec<f64> {
    loop {
        if let Some(outcome) = G::outcome(&sim) {
            return outcome.rewards();
        }
        if let Some(estimate) = G::evaluate(root, &sim) {
            return estimate;
        }
```

```rust
use serde::{Deserialize, Deserializer, Serialize, Serializer};

/// A tile as players see it: its kind (0..34 = 1-9m, 1-9p, 1-9s, then
/// E S W N P F C) and whether it is a red five.
#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash, PartialOrd, Ord)]
pub struct Tile {
    kind: u8,
    red: bool,
}

const SUITS: [char; 3] = ['m', 'p', 's'];
const HONORS: [&str; 7] = ["E", "S", "W", "N", "P", "F", "C"];
/// riichienv's ids for the red fives (5m, 5p, 5s).
const RED_IDS: [u8; 3] = [16, 52, 88];

impl Tile {
    /// `red` is only meaningful for a five of a suit.
    pub fn new(kind: u8, red: bool) -> Self {
        assert!(kind < 34, "tile kind {kind}");
        let is_five = kind < 27 && kind % 9 == 4;
        Self { kind, red: red && is_five }
    }

    /// From riichienv's tile id (0..136, four copies per kind).
    pub fn from_id(id: u8) -> Self {
        Self { kind: id / 4, red: RED_IDS.contains(&id) }
    }

    pub fn kind(self) -> u8 {
        self.kind
    }

    pub fn is_red(self) -> bool {
        self.red
    }

    pub fn is_honor(self) -> bool {
        self.kind >= 27
    }

    pub fn is_terminal(self) -> bool {
        self.kind < 27 && matches!(self.kind % 9, 0 | 8)
    }

    /// Whether engine tile `id` is this tile (same kind, same redness).
    pub fn matches_id(self, id: u8) -> bool {
        Self::from_id(id) == self
    }

    pub fn notation(self) -> String {
        if self.is_honor() {
            return HONORS[usize::from(self.kind - 27)].to_owned();
        }
        let number = self.kind % 9 + 1;
        let suit = SUITS[usize::from(self.kind / 9)];
        if self.red {
            format!("{number}{suit}r")
        } else {
            format!("{number}{suit}")
        }
    }

    pub fn parse(text: &str) -> Option<Self> {
        if let Some(i) = HONORS.iter().position(|&h| h == text) {
            return Some(Self { kind: 27 + i as u8, red: false });
        }
        let mut chars = text.chars();
        let number = chars.next()?.to_digit(10)? as u8;
        let suit = SUITS.iter().position(|&s| Some(s) == chars.next())? as u8;
        let red = match chars.next() {
            None => false,
            Some('r') if number == 5 => true,
            Some(_) => return None,
        };
        if chars.next().is_some() || !(1..=9).contains(&number) {
            return None;
        }
        Some(Self { kind: suit * 9 + number - 1, red })
    }
}

impl Serialize for Tile {
    fn serialize<S: Serializer>(&self, serializer: S) -> Result<S::Ok, S::Error> {
        serializer.serialize_str(&self.notation())
    }
}

impl<'de> Deserialize<'de> for Tile {
    fn deserialize<D: Deserializer<'de>>(deserializer: D) -> Result<Self, D::Error> {
        let text = String::deserialize(deserializer)?;
        Tile::parse(&text).ok_or_else(|| serde::de::Error::custom(format!("tuile inconnue : {text}")))
    }
}
```

```rust
use riichienv_core::action::{Action as EngineAction, ActionType};
use serde::{Deserialize, Serialize};

use crate::Tile;

/// What a player can do, in the players' terms (tiles by notation).
#[derive(Clone, Debug, PartialEq, Eq, Hash, Serialize, Deserialize)]
#[serde(tag = "type")]
pub enum Action {
    Discard { tile: Tile },
    /// Declares riichi; the discard follows as the next action.
    Riichi,
    Chi { tile: Tile, with: [Tile; 2] },
    Pon { tile: Tile, with: [Tile; 2] },
    Daiminkan { tile: Tile },
    Ankan { tile: Tile },
    Kakan { tile: Tile },
    Tsumo,
    Ron,
    KyushuKyuhai,
    Pass,
}

fn pair(ids: &[u8]) -> Option<[Tile; 2]> {
    match ids {
        [a, b] => Some([Tile::from_id(*a), Tile::from_id(*b)]),
        _ => None,
    }
}

/// Our view of an engine action; `None` for three-player actions (kita).
pub(crate) fn from_engine(a: &EngineAction) -> Option<Action> {
    let tile = || a.tile.map(Tile::from_id);
    Some(match a.action_type {
        ActionType::Discard => Action::Discard { tile: tile()? },
        ActionType::Riichi => Action::Riichi,
        ActionType::Chi => Action::Chi { tile: tile()?, with: pair(&a.consume_tiles)? },
        ActionType::Pon => Action::Pon { tile: tile()?, with: pair(&a.consume_tiles)? },
        ActionType::Daiminkan => Action::Daiminkan { tile: tile()? },
        ActionType::Ankan => Action::Ankan { tile: Tile::from_id(*a.consume_tiles.first()?) },
        ActionType::Kakan => Action::Kakan { tile: a.tile.or(a.consume_tiles.first().copied()).map(Tile::from_id)? },
        ActionType::Tsumo => Action::Tsumo,
        ActionType::Ron => Action::Ron,
        ActionType::KyushuKyuhai => Action::KyushuKyuhai,
        ActionType::Pass => Action::Pass,
        ActionType::Kita => return None,
    })
}

/// The engine's legal actions in our terms, one per distinct `Action`
/// (copies of the same tile are the same move), each paired with the first
/// engine action that realises it.
pub(crate) fn legal(engine: &[EngineAction]) -> Vec<(Action, EngineAction)> {
    let mut out: Vec<(Action, EngineAction)> = Vec::new();
    for e in engine {
        if let Some(a) = from_engine(e) {
            if !out.iter().any(|(seen, _)| *seen == a) {
                out.push((a, e.clone()));
            }
        }
    }
    out
}
```

```rust
//! Imposed walls, for tests and tools (puzzles, reproductions).

use crate::Tile;

/// A first-hand wall in draw order. `hands[0]` is the dealer (seat 0); each
/// hand is 13 space-separated tiles; `draws` are the next draws in turn
/// order. The rest (and the 14-tile dead wall) is filled with unused ids.
pub fn wall(hands: [&str; 4], draws: &[&str]) -> Vec<u8> {
    let mut used = [false; 136];
    let mut take = |text: &str| -> u8 {
        let tile = Tile::parse(text).unwrap_or_else(|| panic!("tuile {text}"));
        let base = tile.kind() * 4;
        let id = (base..base + 4)
            .find(|&id| !used[usize::from(id)] && tile.matches_id(id))
            .unwrap_or_else(|| panic!("plus de {text} disponible"));
        used[usize::from(id)] = true;
        id
    };
    let hands: Vec<Vec<u8>> = hands
        .iter()
        .map(|h| {
            let ids: Vec<u8> = h.split_whitespace().map(&mut take).collect();
            assert_eq!(ids.len(), 13, "{h}");
            ids
        })
        .collect();
    let mut order = Vec::with_capacity(136);
    for block in 0..3 {
        for hand in &hands {
            order.extend_from_slice(&hand[block * 4..block * 4 + 4]);
        }
    }
    for hand in &hands {
        order.push(hand[12]);
    }
    for d in draws {
        order.push(take(d));
    }
    order.extend((0..136u8).filter(|&id| !used[usize::from(id)]));
    order
}
```

```rust
use std::collections::{BTreeMap, HashMap};
use std::sync::Arc;

use ludo_core::Seat;
use riichienv_core::action::{Action as EngineAction, Phase};
use riichienv_core::rule::GameRule;
use riichienv_core::state::legal_actions::GameStateLegalActions;
use riichienv_core::state::GameState;
use serde::{Deserialize, Deserializer, Serialize, Serializer};

use crate::action::{self, Action};

/// riichienv's game mode 2: hanchan (East and South, Mahjong Soul extension).
const HANCHAN: u8 = 2;

/// One engine step: every answer given for one decision.
type Step = Vec<(Seat, Action)>;

/// Accepted steps as a persistent list: the AI clones states constantly,
/// and a clone shares the history instead of copying it.
#[derive(Clone, Debug, Default)]
struct History(Option<Arc<Node>>);

#[derive(Debug)]
struct Node {
    step: Step,
    prev: History,
}

impl History {
    fn push(&mut self, step: Step) {
        let prev = std::mem::take(self);
        self.0 = Some(Arc::new(Node { step, prev }));
    }

    fn to_vec(&self) -> Vec<Step> {
        let mut steps = Vec::new();
        let mut at = &self.0;
        while let Some(node) = at {
            steps.push(node.step.clone());
            at = &node.prev.0;
        }
        steps.reverse();
        steps
    }
}

#[derive(Clone, Debug)]
pub struct State {
    seed: u64,
    /// Imposed first-hand wall (tests), in draw order.
    wall: Option<Vec<u8>>,
    history: History,
    /// Answers received for the current decision, not yet given to the engine.
    pub(crate) answers: BTreeMap<Seat, Action>,
    pub(crate) inner: GameState,
}

/// What is saved: the engine is rebuilt by replaying it.
#[derive(Serialize, Deserialize)]
struct Saved {
    seed: u64,
    wall: Option<Vec<u8>>,
    steps: Vec<Step>,
    answers: Vec<(Seat, Action)>,
}

impl State {
    pub fn start(seed: u64, wall: Option<Vec<u8>>) -> Self {
        let mut inner = GameState::new(HANCHAN, true, Some(seed), 0, GameRule::default_mjsoul());
        if let Some(w) = &wall {
            assert_eq!(w.len(), 136, "a wall has 136 tiles");
            inner._initialize_round(0, 0, 0, 0, Some(w.clone()), None);
        }
        Self { seed, wall, history: History::default(), answers: BTreeMap::new(), inner }
    }

    pub fn scores(&self) -> [i32; 4] {
        std::array::from_fn(|i| self.inner.players[i].score)
    }

    /// Identifies the hand being played: it changes when a hand ends.
    pub(crate) fn hand_key(&self) -> (u8, u8, u8) {
        (self.inner.round_wind, self.inner.kyoku_idx, self.inner.honba)
    }

    pub(crate) fn is_pending(&self, seat: Seat) -> bool {
        !self.inner.is_done && self.inner.active_players.contains(&seat.0) && !self.answers.contains_key(&seat)
    }

    pub(crate) fn pending_seats(&self) -> Vec<Seat> {
        let mut seats: Vec<Seat> = (0..4u8).map(Seat).filter(|&s| self.is_pending(s)).collect();
        seats.sort();
        seats
    }

    pub(crate) fn in_claim_window(&self) -> bool {
        self.inner.phase == Phase::WaitResponse
    }

    /// Legal actions of a pending seat, each with the engine action behind it.
    pub(crate) fn engine_legal(&self, seat: Seat) -> Vec<(Action, EngineAction)> {
        if !self.is_pending(seat) {
            return Vec::new();
        }
        action::legal(&self.inner._get_legal_actions_internal(seat.0))
    }

    /// Records `seat`'s answer; runs the engine once every asked seat has answered.
    /// The caller has checked that the action is legal.
    pub(crate) fn answer(&mut self, seat: Seat, action: Action) {
        self.answers.insert(seat, action);
        if self.inner.active_players.iter().all(|p| self.answers.contains_key(&Seat(*p))) {
            self.flush();
        }
    }

    fn flush(&mut self) {
        let step: Step = std::mem::take(&mut self.answers).into_iter().collect();
        let mut engine_actions = HashMap::new();
        for (seat, a) in &step {
            let legal = action::legal(&self.inner._get_legal_actions_internal(seat.0));
            let (_, e) = legal.into_iter().find(|(ours, _)| ours == a).expect("answers are validated");
            engine_actions.insert(seat.0, e);
        }
        self.inner.step(&engine_actions);
        if let Some(e) = self.inner.last_error.take() {
            panic!("riichienv refused validated answers {step:?}: {e}");
        }
        self.history.push(step);
    }

    fn replay(saved: Saved) -> Result<Self, String> {
        let mut s = Self::start(saved.seed, saved.wall);
        for (i, step) in saved.steps.into_iter().enumerate() {
            for (seat, a) in step {
                if !s.engine_legal(seat).iter().any(|(ours, _)| *ours == a) {
                    return Err(format!("étape {i} : {a:?} illégal pour le siège {}", seat.0));
                }
                s.answer(seat, a);
            }
        }
        for (seat, a) in saved.answers {
            if !s.engine_legal(seat).iter().any(|(ours, _)| *ours == a) {
                return Err(format!("réponse en attente {a:?} illégale pour le siège {}", seat.0));
            }
            s.answers.insert(seat, a);
        }
        Ok(s)
    }
}

impl Serialize for State {
    fn serialize<S: Serializer>(&self, serializer: S) -> Result<S::Ok, S::Error> {
        Saved {
            seed: self.seed,
            wall: self.wall.clone(),
            steps: self.history.to_vec(),
            answers: self.answers.iter().map(|(s, a)| (*s, a.clone())).collect(),
        }
        .serialize(serializer)
    }
}

impl<'de> Deserialize<'de> for State {
    fn deserialize<D: Deserializer<'de>>(deserializer: D) -> Result<Self, D::Error> {
        State::replay(Saved::deserialize(deserializer)?).map_err(serde::de::Error::custom)
    }
}
```

```rust
use serde::{Deserialize, Serialize};

pub struct Riichi;

/// Hanchan with Mahjong Soul rules: no options.
#[derive(Clone, Debug, Default, PartialEq, Eq, Serialize, Deserialize)]
pub struct Config {}

impl Game for Riichi {
    type State = State;
    type Action = Action;
    type View = View;
    type Config = Config;

    fn meta() -> GameMeta {
        GameMeta {
            id: "riichi",
            name: "Mahjong Riichi",
            min_players: 4,
            max_players: 4,
            hidden_info: true,
            clock: true,
        }
    }

    fn new(_config: &Config, _players: u8, seed: u64) -> State {
        State::start(seed, None)
    }

    fn pending(s: &State) -> Pending {
        Pending(s.pending_seats())
    }

    fn legal_actions(s: &State, seat: Seat) -> Vec<Action> {
        s.engine_legal(seat).into_iter().map(|(a, _)| a).collect()
    }

    fn apply(s: &mut State, seat: Seat, action: &Action) -> Result<(), Illegal> {
        let legal = s.engine_legal(seat);
        if legal.is_empty() {
            return Err(Illegal::new("Ce n'est pas à toi de jouer."));
        }
        if !legal.iter().any(|(a, _)| a == action) {
            return Err(Illegal::new("Ce coup n'est pas permis."));
        }
        s.answer(seat, action.clone());
        Ok(())
    }

    fn view(s: &State, viewer: Viewer) -> View {
        View::of(s, viewer)
    }

    /// Final ranking by score; ties go to the earlier seat (Mahjong Soul).
    fn outcome(s: &State) -> Option<Outcome> {
        if !s.inner.is_done {
            return None;
        }
        let scores = s.scores();
        let mut order: Vec<usize> = (0..4).collect();
        order.sort_by_key(|&i| (std::cmp::Reverse(scores[i]), i));
        let mut ranks = vec![0u8; 4];
        for (rank, &seat) in order.iter().enumerate() {
            ranks[seat] = rank as u8;
        }
        Some(Outcome::Ranked(ranks))
    }

    /// Pass a call; otherwise discard the drawn tile; otherwise the first
    /// legal discard; otherwise the first legal action.
    fn timeout_action(s: &State, seat: Seat) -> Option<Action> {
        let legal = Self::legal_actions(s, seat);
        if legal.is_empty() {
            return None;
        }
        if legal.contains(&Action::Pass) {
            return Some(Action::Pass);
        }
        if let Some(drawn) = s.inner.drawn_tile.map(Tile::from_id) {
            let tsumogiri = Action::Discard { tile: drawn };
            if legal.contains(&tsumogiri) {
                return Some(tsumogiri);
            }
        }
        legal.iter().find(|a| matches!(a, Action::Discard { .. })).or(legal.first()).cloned()
    }

    /// During a call window, being asked is secret: each seat only sees itself.
    fn visible_pending(s: &State, viewer: Viewer) -> Pending {
        if !s.in_claim_window() {
            return Self::pending(s);
        }
        match viewer {
            Viewer::Seat(me) if s.is_pending(me) => Pending::one(me),
            _ => Pending::none(),
        }
    }
}
```

```rust
/// Ura-dora indicators, next to each revealed dora indicator in the dead wall.
pub(crate) fn ura_indicators(g: &GameState) -> Vec<u8> {
    let shift = usize::from(g.wall.rinshan_draw_count);
    (0..g.wall.dora_indicators.len())
        .filter_map(|i| g.wall.tiles.get((5 + 2 * i).saturating_sub(shift)).copied())
        .collect()

fn evaluate(
    g: &GameState,
    pid: u8,
    from: Option<Seat>,
    win_tile: u8,
    cond: Conditions,
    shown: Vec<u8>,
) -> WinView {
    let p = &g.players[usize::from(pid)];
    let ura = if p.riichi_declared { ura_indicators(g) } else { Vec::new() };
    let res = HandEvaluator::new(p.hand.clone(), p.melds.clone()).calc(
        win_tile,
        g.wall.dora_indicators.clone(),
        ura,
        Some(cond),
    );
    // Mahjong Soul rules enable every double yakuman: riichienv's cap never applies.
    let points = if from.is_some() {
        res.ron_agari
    } else if pid == g.oya {
        res.tsumo_agari_ko * 3
    } else {
        res.tsumo_agari_oya + 2 * res.tsumo_agari_ko
    };
    WinView {
        seat: Seat(pid),
        from,
        hand: tiles(&shown),
        melds: meld_views(&p.melds, pid),
        win_tile: Tile::from_id(win_tile),
        yaku: res
            .yaku
            .iter()
            .filter_map(|&id| get_yaku_by_id(id))
            .map(|y| YakuName { name: y.name_en, name_ja: y.name })
            .collect(),
        han: res.han,
        fu: res.fu,
        points,
        yakuman: res.yakuman,
    }
}

/// The winners in `step`, before the engine applies it.
pub(crate) fn preview(g: &GameState, claim: Option<(u8, u8)>, step: &[(Seat, Action)]) -> Vec<WinView> {
    if let Some((seat, _)) = step.iter().find(|(_, a)| *a == Action::Tsumo) {
        let pid = seat.0;
        let p = &g.players[usize::from(pid)];
        let cond = Conditions {
            tsumo: true,
            riichi: p.riichi_declared,
            double_riichi: p.double_riichi_declared,
            ippatsu: p.ippatsu_cycle,
            haitei: g.wall.drawable_count == 0 && !g.is_rinshan_flag,
            rinshan: g.is_rinshan_flag,
            tsumo_first_turn: g.is_first_turn && g.players.iter().all(|q| q.melds.is_empty()),
            player_wind: EngineWind::from((pid + NP - g.oya) % NP),
            round_wind: EngineWind::from(g.round_wind),
            riichi_sticks: g.riichi_sticks,
            honba: u32::from(g.honba),
            ..Default::default()
        };
        let win_tile = g.drawn_tile.unwrap_or(0);
        return vec![evaluate(g, pid, None, win_tile, cond, p.hand.clone())];
    }
    let Some((discarder, win_tile)) = claim else { return Vec::new() };
    let mut ronners: Vec<u8> = step.iter().filter(|(_, a)| *a == Action::Ron).map(|(s, _)| s.0).collect();
    // The first winner after the discarder takes the honba.
    ronners.sort_by_key(|&p| (p + NP - discarder) % NP);
    ronners
        .iter()
        .enumerate()
        .map(|(i, &pid)| {
            let p = &g.players[usize::from(pid)];
            let cond = Conditions {
                tsumo: false,
                riichi: p.riichi_declared,
                double_riichi: p.double_riichi_declared,
                ippatsu: p.ippatsu_cycle,
                haitei: false,
                houtei: g.wall.drawable_count == 0 && !g.is_rinshan_flag,
                rinshan: false,
                chankan: g.pending_kan.is_some(),
                tsumo_first_turn: false,
                player_wind: EngineWind::from((pid + NP - g.oya) % NP),
                round_wind: EngineWind::from(g.round_wind),
                riichi_sticks: g.riichi_sticks,
                honba: if i == 0 { u32::from(g.honba) } else { 0 },
                ..Default::default()
            };
            let mut shown = p.hand.clone();
            shown.push(win_tile);
            evaluate(g, pid, Some(Seat(discarder)), win_tile, cond, shown)
        })
        .collect()
}
```

```rust
use ludo_core::{Determinize, Seat};
use rand::seq::SliceRandom;
use rand::Rng;
use riichienv_core::action::ActionType;
use riichienv_core::state::legal_actions::GameStateLegalActions;

use crate::{Riichi, State};

impl State {
    /// Wall positions `observer` has seen: the revealed dora indicators.
    fn revealed_wall_positions(&self) -> Vec<usize> {
        let shift = usize::from(self.inner.wall.rinshan_draw_count);
        (0..self.inner.wall.dora_indicators.len()).map(|k| (4 + 2 * k).saturating_sub(shift)).collect()
    }

    /// In a call window, who may call depends on the (redrawn) hands.
    fn recompute_claims(&mut self, observer: Seat) {
        let Some((discarder, tile)) = self.claim_source() else { return };
        let chankan = self.inner.pending_kan.is_some();
        let mut active = Vec::new();
        for i in 0..4u8 {
            if i == discarder {
                continue;
            }
            if i == observer.0 {
                if self.inner.active_players.contains(&i) {
                    active.push(i);
                }
                continue;
            }
            let (mut claims, _) = self.inner._get_claim_actions_for_player(i, discarder, tile);
            if chankan {
                // Only a win can rob a kan.
                claims.retain(|a| a.action_type == ActionType::Ron);
            }
            if claims.is_empty() {
                self.inner.current_claims.remove(&i);
            } else {
                self.inner.current_claims.insert(i, claims);
                active.push(i);
            }
        }
        self.inner.active_players = active;
    }
}

impl Determinize for Riichi {
    /// Redraws everything `observer` cannot see: the other hands, the live
    /// wall and the unrevealed dead wall (sizes and revealed indicators kept),
    /// then who may call and the answers others already gave.
    /// Approximation: a redrawn hand of a player in riichi is not forced tenpai.
    fn determinize<R: Rng + ?Sized>(s: &State, observer: Seat, rng: &mut R) -> State {
        let mut d = s.clone();
        if d.inner.is_done {
            return d;
        }
        let me = observer.index();
        let revealed = d.revealed_wall_positions();
        let mut pool: Vec<u8> = (0..4).filter(|&p| p != me).flat_map(|p| d.inner.players[p].hand.clone()).collect();
        pool.extend(d.inner.wall.tiles.iter().enumerate().filter(|(i, _)| !revealed.contains(i)).map(|(_, &t)| t));
        // Sorted first: the same knowledge must give the same world, whatever the truth.
        pool.sort_unstable();
        pool.shuffle(rng);
        let mut fresh = pool.into_iter();

        let drawer = usize::from(d.inner.current_player);
        let old_drawn = d.inner.drawn_tile;
        let mut new_drawn = None;
        for p in (0..4).filter(|&p| p != me) {
            for slot in d.inner.players[p].hand.iter_mut() {
                let tile = fresh.next().expect("pool size matches");
                if p == drawer && Some(*slot) == old_drawn && new_drawn.is_none() {
                    new_drawn = Some(tile);
                }
                *slot = tile;
            }
            d.inner.players[p].hand.sort_unstable();
        }
        for (i, slot) in d.inner.wall.tiles.iter_mut().enumerate() {
            if !revealed.contains(&i) {
                *slot = fresh.next().expect("pool size matches");
            }
        }
        if drawer != me && new_drawn.is_some() {
            d.inner.drawn_tile = new_drawn;
        }

        if d.in_claim_window() {
            d.recompute_claims(observer);
        }
        let others: Vec<Seat> = d.answers.keys().copied().filter(|&x| x != observer).collect();
        for seat in others {
            d.answers.remove(&seat);
            let legal = d.engine_legal(seat);
```

```rust
use ludo_core::ai::{Budget, Level};
use ludo_core::{Game, Heuristics, Seat};
use rand::seq::SliceRandom;
use rand::Rng;
use riichienv_core::shanten::calculate_shanten;

use crate::{standings, Action, Riichi, State, Tile};

impl State {
    /// Dragons, the round wind and `seat`'s wind give a yaku as a triplet.
    fn is_yakuhai(&self, seat: Seat, tile: Tile) -> bool {
        let kind = tile.kind();
        let seat_wind = (seat.0 + 4 - self.inner.oya) % 4;
        kind >= 31 || kind == 27 + self.inner.round_wind || kind == 27 + seat_wind
    }

    fn shanten_without(&self, seat: Seat, tile: Tile) -> i32 {
        let mut hand: Vec<u32> = self.inner.players[seat.index()].hand.iter().map(|&id| u32::from(id)).collect();
        if let Some(i) = hand.iter().position(|&id| tile.matches_id(id as u8)) {
            hand.remove(i);
        }
        calculate_shanten(&hand)
    }

    /// How much a tile is worth keeping, all else equal (lower: discard first).
    fn keep_value(&self, seat: Seat, tile: Tile) -> u8 {
        let base = if tile.is_honor() {
            u8::from(self.is_yakuhai(seat, tile))
        } else if tile.is_terminal() {
            2
        } else if matches!(tile.kind() % 9, 1 | 7) {
            3
        } else {
            4
        };
        base + if tile.is_red() { 10 } else { 0 }
    }
}

impl Heuristics for Riichi {
    /// Win if possible; riichi when tenpai; on a call window pass, except a
    /// pon that gives a yaku; otherwise the discard that lowers shanten most,
    /// keeping the most valuable tiles.
    fn rollout_action<R: Rng + ?Sized>(s: &State, seat: Seat, rng: &mut R) -> Action {
        let legal = Self::legal_actions(s, seat);
        if let Some(win) = legal.iter().find(|a| matches!(a, Action::Tsumo | Action::Ron)) {
            return win.clone();
        }
        if legal.contains(&Action::Riichi) {
            return Action::Riichi;
        }
        if legal.contains(&Action::Pass) {
            return legal
                .iter()
                .find(|a| matches!(a, Action::Pon { tile, .. } if s.is_yakuhai(seat, *tile)))
                .cloned()
                .unwrap_or(Action::Pass);
        }
        let discards: Vec<Tile> = legal
            .iter()
            .filter_map(|a| match a {
                Action::Discard { tile } => Some(*tile),
                _ => None,
            })
            .collect();
        match discards.iter().min_by_key(|&&tile| (s.shanten_without(seat, tile), s.keep_value(seat, tile), rng.gen::<u16>())) {
            Some(&tile) => Action::Discard { tile },
            None => legal.choose(rng).expect("a pending seat has a legal action").clone(),
        }
    }

    /// Simulate to the end of the current hand, then estimate the final
    /// ranking from the scores.
    fn evaluate(root: &State, sim: &State) -> Option<Vec<f64>> {
        (!sim.inner.is_done && sim.hand_key() != root.hand_key()).then(|| standings(sim.scores()).rewards())
    }

    fn budget(level: Level, timed: bool) -> Option<Budget> {
        match (level, timed) {
            (Level::Easy, _) => None,
            (Level::Medium, true) => Some(Budget::Millis(300)),
            (Level::Medium, false) => Some(Budget::Iterations(30)),
            (Level::Hard, true) => Some(Budget::Millis(1000)),
            (Level::Hard, false) => Some(Budget::Iterations(300)),
        }
    }
}
```

```ts
import type { Seat, SeatClockView } from "../engine/types";

export interface ClockSettings {
  /** Time for each decision. */
  baseMs: number;
  /** Extra time for the whole game, spent once the base time is used up. */
  bankMs: number;
}

export const CLOCK_PRESETS: { id: string; label: string; settings: ClockSettings | null }[] = [
  { id: "5+20", label: "5 + 20 s", settings: { baseMs: 5_000, bankMs: 20_000 } },
  { id: "10+40", label: "10 + 40 s", settings: { baseMs: 10_000, bankMs: 40_000 } },
  { id: "none", label: "Aucun", settings: null },
];

/** Per-seat decision clocks (Mahjong Soul style). Pure: time is passed in. */
export class Clocks {
  private banks = new Map<Seat, number>();
  private started = new Map<Seat, number>();

  constructor(
    readonly settings: ClockSettings,
    banks: [Seat, number][] = [],
  ) {
    for (const [seat, bank] of banks) this.banks.set(seat, bank);
  }

  private bank(seat: Seat): number {
    return this.banks.get(seat) ?? this.settings.bankMs;
  }

  private spend(seat: Seat, used: number) {
    const over = Math.max(0, used - this.settings.baseMs);
    this.banks.set(seat, Math.max(0, this.bank(seat) - over));
  }

  /** `seat` has just decided: its time stops (a new decision starts at the next `sync`). */
  finish(seat: Seat, now: number) {
    const since = this.started.get(seat);
    if (since === undefined) return;
    this.spend(seat, now - since);
    this.started.delete(seat);
  }

  /** `pending`: the timed seats that must decide now. */
  sync(pending: Seat[], now: number) {
    for (const seat of [...this.started.keys()]) {
      if (!pending.includes(seat)) this.finish(seat, now);
    }
    for (const seat of pending) {
      if (!this.started.has(seat)) this.started.set(seat, now);
    }
  }

  view(seat: Seat, now: number): SeatClockView | null {
    const since = this.started.get(seat);
    if (since === undefined) return null;
    const used = now - since;
    const { baseMs } = this.settings;
    return {
      seat,
      baseMs: Math.max(0, baseMs - used),
      bankMs: Math.max(0, this.bank(seat) - Math.max(0, used - baseMs)),
    };
  }

  views(now: number): SeatClockView[] {
    return [...this.started.keys()]
      .sort((a, b) => a - b)
      .map((seat) => this.view(seat, now))
      .filter((v): v is SeatClockView => v !== null);
  }

  /** When the default action is due, or null if `seat` is not deciding. */
  deadline(seat: Seat): number | null {
    const since = this.started.get(seat);
    return since === undefined ? null : since + this.settings.baseMs + this.bank(seat);
  }

  toJSON(): [Seat, number][] {
    return [...this.banks.entries()].sort(([a], [b]) => a - b);
  }
}
```

```ts
import { AiClient, EngineClient, randomSeed } from "../engine/clients";
import type { AiRequest, Level, Seat, SeatClockView, Snapshot } from "../engine/types";
import { Clocks, type ClockSettings } from "./clock";
import { errorMessage } from "./names";
import { StaleActionError, isStale } from "./rev";

export type TableSeat =
  | { kind: "local"; name: string }
  | { kind: "ai"; level: Level; name: string }
  | { kind: "remote"; name: string };

interface TableHooks {
  onSnapshot(s: Snapshot): void;
  /** After each snapshot: the match log, for saving. */
  onLog?(log: unknown, s: Snapshot): void;
  onError(message: string): void;
}

/** What `Table` needs from the engine worker (a fake in tests). */
export interface EngineLike {
  newMatch(gameId: string, players: number, seed: number, config?: unknown): Promise<unknown>;
  importLog(gameId: string, log: unknown): Promise<unknown>;
  apply(seat: Seat, action: unknown): Promise<unknown>;
  snapshot(viewers: (Seat | null)[]): Promise<Snapshot>;
  exportState(): Promise<unknown>;
  exportLog(): Promise<unknown>;
  timeoutAction(seat: Seat): Promise<unknown | null>;
  dispose(): void;
}

export interface AiLike {
  move(req: AiRequest): Promise<unknown>;
  dispose(): void;
}

export interface TableOptions {
  /** Decision clock for human seats (online play). */
  clock?: ClockSettings | null;
  /** Saved banks, when resuming. */
  banks?: [Seat, number][];
  engine?: EngineLike;
  ai?: AiLike;
  now?: () => number;
}

/** AI moves are shown after at least this long, so humans can follow. */
export const AI_MIN_DELAY_MS = 400;
/** A seat with a single legal action plays it after this long. */
export const AUTO_PLAY_MS = 300;

/**
 * The authoritative game: engine, AI seats, clocks. Used by local play and by
 * the host. Engine calls are serialized, and every change produces a
 * snapshot for all seats.
 */
export class Table {
  private engine: EngineLike;
  private ai: AiLike;
  private clocks: Clocks | null;
  private now: () => number;
  private queue: Promise<unknown> = Promise.resolve();
  private thinking = new Set<Seat>();
  private timers = new Set<ReturnType<typeof setTimeout>>();
  private disposed = false;
  snapshot: Snapshot | null = null;

  constructor(
    readonly gameId: string,
    readonly seats: TableSeat[],
    private hooks: TableHooks,
    options: TableOptions = {},
  ) {
    this.engine = options.engine ?? new EngineClient();
    this.ai = options.ai ?? new AiClient();
    this.clocks = options.clock ? new Clocks(options.clock, options.banks) : null;
    this.now = options.now ?? (() => performance.now());
  }

  start(seed: number, config: unknown = null): Promise<void> {
    return this.serial(async () => {
      await this.engine.newMatch(this.gameId, this.seats.length, seed, config);
      await this.refresh();
    });
  }

  resume(log: unknown): Promise<void> {
    return this.serial(async () => {
      await this.engine.importLog(this.gameId, log);
      await this.refresh();
    });
  }

  /**
   * Applies `action` for `seat`. Rejects with the engine's message when it
   * is illegal, or with `StaleActionError` when `rev` is given and the game
   * has moved on since.
   */
  submit(seat: Seat, action: unknown, rev?: number): Promise<void> {
    return this.serial(async () => {
      if (rev !== undefined && this.snapshot && isStale(rev, this.snapshot.rev)) throw new StaleActionError();
      await this.engine.apply(seat, action);
      this.clocks?.finish(seat, this.now());
      await this.refresh();
    });
  }

  /** Time left for every timed seat that is deciding. */
  clockViews(): SeatClockView[] {
    return this.clocks?.views(this.now()) ?? [];
  }

  /** Remaining banks, to save with the game. */
  banks(): [Seat, number][] {
    return this.clocks?.toJSON() ?? [];
  }

  dispose() {
    this.disposed = true;
    for (const t of this.timers) clearTimeout(t);
    this.timers.clear();
    this.engine.dispose();
    this.ai.dispose();
  }

  private serial<T>(task: () => Promise<T>): Promise<T> {
    const run = this.queue.then(task);
    this.queue = run.catch(() => undefined);
    return run;
  }

  private later(ms: number, task: () => void) {
    const timer = setTimeout(() => {
      this.timers.delete(timer);
      if (!this.disposed) task();
    }, Math.max(0, ms));
    this.timers.add(timer);
  }

  private async refresh() {
    const viewers: (Seat | null)[] = [...this.seats.keys(), null];
    const s = await this.engine.snapshot(viewers);
    if (this.disposed) return;
    this.snapshot = s;
    for (const t of this.timers) clearTimeout(t);
    this.timers.clear();
    this.syncClocks(s);
    this.hooks.onSnapshot(s);
    if (this.hooks.onLog) this.hooks.onLog(await this.engine.exportLog(), s);
    this.autoPlay(s);
    this.runAi(s);
  }

  private humanPending(s: Snapshot): Seat[] {
    return s.pending.filter((seat) => this.seats[seat]?.kind !== "ai");
  }

  private syncClocks(s: Snapshot) {
    if (!this.clocks) return;
    const now = this.now();
    const humans = this.humanPending(s);
    this.clocks.sync(humans, now);
    for (const seat of humans) {
      const deadline = this.clocks.deadline(seat);
      if (deadline !== null) this.later(deadline - now, () => void this.expire(seat, s.rev));
    }
  }

  /** The seat's time ran out: the game's default action, through the normal path. */
  private async expire(seat: Seat, rev: number) {
    try {
      const action = await this.serial(() => this.engine.timeoutAction(seat));
      if (action !== null) await this.submit(seat, action, rev);
    } catch (e) {
      if (!(e instanceof StaleActionError)) this.hooks.onError(errorMessage(e));
    }
  }

  /** A human seat with a single legal action plays it. */
  private autoPlay(s: Snapshot) {
    for (const seat of this.humanPending(s)) {
      const legal = s.views.find((v) => v.viewer === seat)?.legalActions ?? [];
      if (legal.length !== 1) continue;
      this.later(AUTO_PLAY_MS, () => {
        this.submit(seat, legal[0], s.rev).catch((e) => {
          if (!(e instanceof StaleActionError)) this.hooks.onError(errorMessage(e));
        });
      });
    }
  }

  private runAi(s: Snapshot) {
    for (const seat of s.pending) {
      const setup = this.seats[seat];
      if (setup?.kind !== "ai" || this.thinking.has(seat)) continue;
      this.thinking.add(seat);
      void this.playAi(seat, setup.level);
    }
  }

  private async playAi(seat: Seat, level: Level) {
    const started = this.now();
    for (let attempt = 1; ; attempt++) {
      try {
        const { state, rev } = await this.serial(async () => ({
          state: await this.engine.exportState(),
          rev: this.snapshot?.rev ?? 0,
        }));
        const action = await this.ai.move({ gameId: this.gameId, state, seat, level, seed: randomSeed() });
        await sleep(AI_MIN_DELAY_MS - (this.now() - started));
        if (this.disposed) return;
        this.thinking.delete(seat);
        await this.submit(seat, action, rev);
        return;
      } catch (e) {
        if (this.disposed) return;
        if (e instanceof StaleActionError) {
          // Computed on an old state: the latest snapshot decides whether this seat still has to play.
          this.thinking.delete(seat);
          if (this.snapshot) this.runAi(this.snapshot);
          return;
        }
        if (attempt < 2) continue;
        this.thinking.delete(seat);
        this.hooks.onError(`${this.seats[seat].name} : ${errorMessage(e)}`);
        await this.playFallback(seat);
        return;
      }
    }
  }

  /** The AI could not decide: the game's default action, else its first legal action. */
  private async playFallback(seat: Seat) {
    const rev = this.snapshot?.rev;
    const fallback =
      (await this.serial(() => this.engine.timeoutAction(seat))) ??
      this.snapshot?.views.find((v) => v.viewer === seat)?.legalActions[0];
    if (fallback === undefined || fallback === null) return;
    await this.submit(seat, fallback, rev).catch(() => undefined);
  }
}

function sleep(ms: number) {
  return new Promise<void>((resolve) => setTimeout(resolve, Math.max(0, ms)));
}
```

```tsx
import type { Tile } from "./types";

const HONORS: Record<string, string> = { E: "Ton", S: "Nan", W: "Shaa", N: "Pei", P: "Haku", F: "Hatsu", C: "Chun" };
const SUITS: Record<string, string> = { m: "Man", p: "Pin", s: "Sou" };
const BASE = `${import.meta.env.BASE_URL}tiles/`;

export function tileFile(tile: Tile): string {
  if (HONORS[tile]) return `${HONORS[tile]}.svg`;
  const suit = SUITS[tile[1]];
  return tile.endsWith("r") ? `${suit}5-Dora.svg` : `${suit}${tile[0]}.svg`;
}

type Size = "sm" | "md" | "lg";

interface TileProps {
  tile: Tile;
  size?: Size;
  /** Riichi declaration tile, or a called tile. */
  sideways?: boolean;
  dim?: boolean;
  onClick?: () => void;
}

export function TileImg({ tile, size = "md", sideways, dim, onClick }: TileProps) {
  const cls = ["tile", `tile-${size}`, sideways && "sideways", dim && "dim", onClick && "clickable"].filter(Boolean).join(" ");
  return (
    <span className={cls} onClick={onClick} title={tile} role={onClick ? "button" : undefined}>
      <img src={`${BASE}Front.svg`} alt="" />
      <img className="face" src={`${BASE}${tileFile(tile)}`} alt={tile} />
    </span>
  );
}

export function TileBack({ size = "sm" }: { size?: Size }) {
  return (
    <span className={`tile tile-${size}`}>
      <img src={`${BASE}Back.svg`} alt="" />
    </span>
  );
```

```tsx
import { useEffect, useState } from "react";
import type { BoardProps } from "../registry";
import { TileBack, TileImg } from "./tiles";
import type { HandResult, MeldView, PlayerView, RiichiAction, RiichiView, RoundView, Tile, Wind } from "./types";
import "./riichi.css";

const WIND: Record<Wind, string> = { E: "Est", S: "Sud", W: "Ouest", N: "Nord" };
const DRAW: Record<string, string> = { Exhaustive: "Mur épuisé", NineTerminals: "Neuf terminaux", Abortive: "Nul abortif" };
const POSITIONS = ["bottom", "right", "top", "left"] as const;

function callLabel(a: RiichiAction): string {
  switch (a.type) {
    case "Riichi":
      return "Riichi";
    case "Tsumo":
      return "Tsumo";
    case "Ron":
      return "Ron";
    case "Pass":
      return "Passer";
    case "KyushuKyuhai":
      return "Neuf terminaux";
    case "Chi":
      return "Chi";
    case "Pon":
      return "Pon";
    case "Daiminkan":
    case "Ankan":
    case "Kakan":
      return "Kan";
    case "Discard":
      return "Défausser";
  }
}

function callTiles(a: RiichiAction): Tile[] {
  switch (a.type) {
    case "Chi":
    case "Pon":
      return [...a.with, a.tile];
    case "Daiminkan":
    case "Ankan":
    case "Kakan":
      return [a.tile];
    default:
      return [];
  }
}

function Melds({ melds }: { melds: MeldView[] }) {
  return (
    <div className="melds">
      {melds.map((m, i) => (
        <span key={i} className="meld">
          {m.tiles.map((t, j) => (
            <TileImg key={j} tile={t} size="sm" />
          ))}
        </span>
      ))}

  );
}

function Pond({ player, position }: { player: PlayerView; position: (typeof POSITIONS)[number] }) {
  return (
    <div className={`pond pond-${position}`}>
      {player.discards.map((d, i) => (

export function RiichiBoard({ view, legalActions, seatNames, submit }: BoardProps) {
  const v = view as RiichiView;
  const legal = legalActions as RiichiAction[];
  const self = v.me ?? 0;
  const order = [0, 1, 2, 3].map((k) => (self + k) % 4);
  const discardable = new Set(legal.flatMap((a) => (a.type === "Discard" ? [a.tile] : [])));
  const calls = legal.filter((a) => a.type !== "Discard");
  const [showHelp, setShowHelp] = useState(true);
  const [dismissed, setDismissed] = useState(0);
  const result = v.lastHand && v.lastHand.number !== dismissed ? v.lastHand : null;

  useEffect(() => {
    if (!result) return;
    const number = result.number;
    const timer = setTimeout(() => setDismissed(number), 8000);
    return () => clearTimeout(timer);
  }, [result?.number]);

  const discard = (tile: Tile) => (discardable.has(tile) ? () => submit({ type: "Discard", tile }) : undefined);

  return (
    <div className="riichi">
      <div className="riichi-table">
        {order.map((seat, k) => (
          <div key={seat} className={`area area-${POSITIONS[k]}`}>
            <Pond player={v.players[seat]} position={POSITIONS[k]} />
          </div>
        ))}
        <Center round={v.round} />
      </div>
      <div className="seats-row">
        {order.slice(1).map((seat) => (
          <Seat key={seat} player={v.players[seat]} name={seatNames[seat]} dealer={v.round.dealer === seat} />
        ))}
      </div>
      <div className="my-area">
        <div className="my-hand">
          {v.hand.map((t, i) => (
            <TileImg key={i} tile={t} size="lg" onClick={discard(t)} dim={discardable.size > 0 && !discardable.has(t)} />
          ))}
          {v.drawn && (
            <span className="drawn">
              <TileImg tile={v.drawn} size="lg" onClick={discard(v.drawn)} />
            </span>
          )}
          <Melds melds={v.players[self].melds} />
        </div>
        <div className="calls">
          {calls.map((a, i) => (
            <button key={i} className={a.type === "Pass" ? undefined : "primary"} onClick={() => submit(a)}>
              {callLabel(a)}{" "}
              {callTiles(a).map((t, j) => (
                <TileImg key={j} tile={t} size="sm" />
              ))}
            </button>
          ))}
          {v.answered && <span className="status">En attente des autres joueurs…</span>}
        </div>
        <div className="help">
          <button onClick={() => setShowHelp((x) => !x)}>{showHelp ? "Masquer l'aide" : "Aide"}</button>
          {showHelp && v.help && (
            <span>
              {v.help.shanten <= 0 && v.help.waits.length > 0 ? (
                <>
                  Tenpai — attentes :{" "}
                  {v.help.waits.map((t) => (
                    <TileImg key={t} tile={t} size="sm" />
                  ))}
                </>
              ) : (
                `Shanten : ${Math.max(0, v.help.shanten)}`
              )}
            </span>
          )}
        </div>
        <div className="seat-label mine">
          <strong>{WIND[v.players[self].seatWind]}</strong> {seatNames[self]} — {v.players[self].score}
          {v.players[self].riichi && <span className="riichi-stick"> riichi</span>}
        </div>
      </div>
      {result && <ResultPanel result={result} names={seatNames} onClose={() => setDismissed(result.number)} />}
    </div>
  );
}
```
